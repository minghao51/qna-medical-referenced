# Notebooks

Interactive tutorials exploring the medical Q&A RAG pipeline.

| Notebook | Description |
|----------|-------------|
| [Data Exploration](01_data_exploration.ipynb) | Explore the medallion data layers (Bronze, Silver, Gold) in the medical Q&A pipeline |
| [Chunking Strategy Analysis](02_chunking_analysis.ipynb) | Analyze different chunking strategies, chunk quality, and raw vs enriched comparison |
| [Ingestion Pipeline](03_ingestion_pipeline.ipynb) | Walk through the full ingestion DAG: download, extract, chunk, enrich, embed, and index |
| [Retrieval Pipeline](04_retrieval_pipeline.ipynb) | Query understanding, expansion, search modes, reranking, and trace analysis |
| [Feature Ablation Analysis](05_ablation_analysis.ipynb) | What actually improves retrieval? Visualizing ablation results across keywords, HyPE, reranking, and query understanding |
